영수증 하이패스 개인정보 처리방침

시행일 2026년 11월 19일

1. 어떤 정보를 다루나요

영수증 하이패스는 사용자가 올린 영수증 사진, 서류에 입력한 내용(제목, 금액, 날짜, 기안자 이름·직책, 지급계좌)을 다룹니다.

2. 어디에 저장되나요

  • 영수증 사진과 서류 내용은 사용자의 기기(브라우저) 안에만 저장됩니다.
  • 영수증 글자 읽기도 사용자의 기기 안에서 처리되며, 사진을 외부 서버로 보내지 않습니다.
  • 운영자는 사용자의 영수증이나 서류를 볼 수 없습니다.

3. 구글 드라이브 연동

  • 폰↔PC 연동을 켜면, 사용자 본인의 구글 드라이브에 영수증 하이패스가 만든 파일만 저장하고 불러옵니다.
  • 요청하는 권한은 drive.file(이 도구가 만든 파일만 접근)뿐이며, 드라이브의 다른 파일은 읽거나 바꾸지 않습니다.
  • 구글 계정 정보는 로그인 확인에만 쓰이고, 따로 보관하거나 다른 곳에 보내지 않습니다.
  • 구글에서 받은 정보는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 제3자 제공

사용자의 정보를 누구에게도 팔거나 제공하지 않습니다.

5. 지우는 방법

  • 브라우저의 사이트 데이터를 지우면 기기에 저장된 내용이 모두 지워집니다.
  • 구글 드라이브의 "영수증 하이패스" 폴더를 지우면 드라이브에 저장된 내용이 지워집니다.
  • 구글 계정 설정의 "타사 앱 및 서비스"에서 언제든 연결을 끊을 수 있습니다.

6. 문의

궁금한 점은 영수증 하이패스 화면의 "자주 묻는 질문"을 보시거나, 화물연대 조혜진 국장에게 문의해 주세요.
